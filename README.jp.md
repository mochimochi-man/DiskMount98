# DiskMount98

mochimochi-man / Uh (X:@calorie0)



PC-98 の DOS フロッピーイメージをドライブとしてマウントし、エクスプローラーで操作できる Windows 用ツールです。ドライバのインストールは不要です。



## 対応形式

* NFD（r0 / r1）、D88、HDM
* FAT12/16 の DOS フォーマットディスク（2HD 1.25MB / 1.44MB、2DD 640KB / 720KB など）



## ダウンロード

[Releases](../../releases) から `DiskMount98.exe` をダウンロードしてください。インストールは不要です。



## 動作環境

Windows 10 / 11（.NET Framework 4.x は標準で入っています）



## 使い方

1. イメージファイルを `DiskMount98.exe` にドロップします。exe を起動してファイルを選んでも開けます。
2. 空いているドライブ文字（Z: から順）にマウントされ、エクスプローラーが開きます。
3. ファイルを変更すると、自動でイメージに書き戻されます。
4. 小窓の「Unmount」で終了します。

※複数のファイルをドロップすると、1 枚ずつ別のドライブになります。



## 注意

* 最初に書き込むとき、元のイメージを `ファイル名.bak` として保存します。
* 8.3 形式に合わない名前は自動で変換されます（例：`新しいテキスト ドキュメント.txt` → `新しい\~1.TXT`）。
* 変更のないファイルの配置はそのまま残ります。起動ディスクを編集しても起動できる状態を保ちます。
* 容量が足りない場合、イメージは変更されず、小窓にエラーが表示されます。
* 書き込み禁止のイメージは読み取り専用でマウントされます。
* エクスプローラーに表示される空き容量はディスクイメージの値ではありません。実際の空き容量は小窓で確認してください。



## ビルド

`build.bat` を実行してください。Windows 標準の `csc.exe`（.NET Framework 4）でビルドするため、Visual Studio は不要です。



## 仕組み

イメージ内のファイルを一時フォルダに展開し、そのフォルダにドライブ文字を割り当てています。フォルダの変更を検知すると FAT を更新し、変わったセクタだけをイメージに書き戻します。
